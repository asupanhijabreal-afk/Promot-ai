# PromptForge 50 — Offline AI Prompt Generator

Versi: 1.0

## Apa ini?
Aplikasi web offline untuk menghasilkan prompt AI yang konkret dan siap copy-paste.
Tidak memakai API, database, CDN, framework eksternal, atau koneksi internet.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Pilih kategori.
4. Pilih jenis pekerjaan.
5. Isi tujuan, audiens, bahasa, gaya, format, data, dan batasan.
6. Klik Generate Prompt.
7. Klik Copy atau Download .txt.

## Struktur produk
- `index.html` — antarmuka.
- `style.css` — tampilan responsif.
- `app.js` — database kategori + logika generator.
- `README.md` — dokumentasi.

## Catatan lisensi penjualan
File ini adalah template aplikasi yang dibuat untuk pengguna. Sebelum menjualnya, tentukan sendiri lisensi Gumroad, harga, branding, dan ketentuan penggunaan.
