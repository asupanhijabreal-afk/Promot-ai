# AI Project Copilot

A static, no-API project planning and prompt-generation tool designed for GitHub Pages and digital-product distribution.

## What it does
- 50 work/industry categories
- Project wizard
- Project brief prompt
- Step-by-step roadmap
- AI prompt chain for research, requirements, planning, execution, review, testing and delivery
- Checklist
- Optional deployment prompt
- Copy individual prompts or the full project kit
- Download generated project kit as TXT
- Dark mode
- Local browser theme preference
- Mobile responsive

## No API required
The tool itself does not call an AI API. It creates structured prompts that the user can copy into their preferred AI assistant.

## GitHub Pages
1. Upload all files/folders to a GitHub repository.
2. Keep `index.html` at the repository root.
3. Settings → Pages → Deploy from branch → main → /(root).
4. Open the published Pages URL.
